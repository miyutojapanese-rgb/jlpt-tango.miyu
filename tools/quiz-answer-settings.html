生徒が回答を送信したあとに点数と正解が見られるようにする設定です。Google フォームのこの設定は API から一括変更できないため、各テストを開いて手動で切り替えます。下のリンクは各テストの「設定」タブを直接開きます。

各テストで設定する内容

フォームを開く → 上部の「設定」タブ

  • 成績の発表「確認後に手動で表示する」ではなく送信直後
  • 不正解だった質問回答者の設定オン
  • 正解回答者の設定オン
  • 点数回答者の設定オン

「テストにする」がオフのフォームは「設定」タブ内のテストをオンにしてから、上の4項目を設定してください。
同じ画面の下にある「全テストのデフォルト設定」は今後作る新しいフォームにだけ適用され、既存のテストは変わりません。
